# bad-media-player

A terrible media player made for a terrible viewing method. Ascii videos on the terminal. Inspired by badapple on everything and my last attempt. This is a attempt to make a self enclosed media player that works in the terminal along with sound.

Motivation :- I was showing someone this old piece of code, when he asked me to try it out on alacritty which was gpu accelerated. I thought why not, and was rather surprised at the smoothness, this has made me re interested in my old toy, lets see where i go with this.
